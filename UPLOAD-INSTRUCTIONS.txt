OPALREADER — CHROMEBOOK / GITHUB FLAT UPLOAD

This package contains no folders.

1. In the GitHub repository, delete the previously uploaded project files or select Add file > Upload files and allow these files to replace files with matching names.
2. Upload every loose file from this package.
3. Commit the upload.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.

The website files are already compiled. GitHub does not need to run npm, Vite, or an Actions workflow.

cloudflare-worker.js is included at the top level only so it is easy to find and copy when creating the Cloudflare Worker. GitHub Pages will not execute it or expose the ElevenLabs API key. The key must only be stored as an encrypted Worker secret.
