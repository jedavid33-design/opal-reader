OPALREADER v1.1.1 - CHROMEBOOK / GITHUB FLAT UPDATE

This package contains no folders.

GITHUB
1. Extract this ZIP.
2. In the existing opal-reader GitHub repository, choose Add file > Upload files.
3. Select every loose file except cloudflare-worker.js and UPLOAD-INSTRUCTIONS.txt.
4. Allow matching website files to replace the old copies and commit the upload.
5. Keep GitHub Pages configured as branch main and folder /(root).

CLOUDFLARE WORKER
1. Open the existing opalreader-api Worker and edit its code.
2. Replace all old Worker code with cloudflare-worker.js and deploy.
3. Keep ALLOWED_ORIGIN, ELEVENLABS_API_KEY, and OPALREADER_ACCESS_TOKEN.
4. GOOGLE_CLOUD_TTS_API_KEY is optional. ElevenLabs works without it.

CROSS-DEVICE BINDINGS
Create a KV namespace (suggested name: opalreader-sync) and bind it to the Worker with the exact variable name OPALREADER_KV.

Create a private R2 bucket (suggested name: opalreader-storage) and bind it to the Worker with the exact variable name OPALREADER_STORAGE.

Never upload provider API keys to GitHub or enter them in the OpalReader app. The app receives only the Worker URL and your private OPALREADER_ACCESS_TOKEN.
