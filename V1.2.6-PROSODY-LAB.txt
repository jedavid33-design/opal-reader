OpalReader v1.2.6 — Prosody Lab

Purpose:
Investigate within-segment voice-register drift without modifying book audio.

Review POV -> Find text in segments now opens a Prosody Lab for the matching segment.
Tests use the exact currently assigned voice/provider/model:
1. Full segment (fresh): new synthesis each tap, useful for testing randomness.
2. Previous + match paragraph: tests preceding-context effects.
3. Match paragraph only: tests whether the wording itself triggers the prosody change.

All Prosody Lab requests are logged as book auditions and use fresh cache keys so repeated
full-segment runs really are separate synthesis requests.

No generated chapter audio or cast assignment is replaced by these tests.
